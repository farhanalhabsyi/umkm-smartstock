# UMKM SmartStock

Sistem Informasi Manajemen Stok Barang Berbasis Website.

## Profil Mitra
- Jenis usaha: Toko kelontong/sembako
- Pencatatan saat ini: Buku tulis/manual
- Target platform: Website responsif

## Permasalahan Awal
Pencatatan stok secara manual berpotensi menyebabkan
kesalahan perhitungan dan kesulitan memantau persediaan.
Permasalahan ini perlu dikonfirmasi melalui observasi mitra.

## Tujuan
1. Mengelola data produk.
2. Mencatat barang masuk dan keluar.
3. Memantau stok terkini.
4. Memberikan peringatan stok menipis.
5. Menyediakan riwayat transaksi dan laporan.

## Teknologi
- Frontend: React.js, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MySQL
- ORM: Prisma
- API: REST API
- Hosting: Online
